# ar-content — ข้อมูลและวิดีโอประจำอุปกรณ์

โฟลเดอร์นี้เก็บ **เนื้อหาที่จะโผล่ใน popup ของแอป AR** เมื่อผู้ใช้แตะเพื่อกางหน้าต่าง
แยกออกจาก [`ar-markers/`](../ar-markers/) ที่เก็บรูปสำหรับให้กล้องตรวจจับ

แอปอ่านโฟลเดอร์นี้โดยตรงผ่าน assets (ประกาศไว้ใน `android-ar/app/build.gradle.kts`)
แก้ไฟล์ที่นี่แล้ว build ใหม่ก็เห็นผลทันที ไม่ต้องคัดลอกไปที่อื่น

## โครงสร้าง

```
ar-content/
├── info/                  ข้อมูลของแต่ละจุด — ชื่อโฟลเดอร์ตรงกับ deviceId
│   ├── dev-A/
│   │   ├── info.txt       ภาษาไทย
│   │   ├── info.en.txt    ภาษาอังกฤษ (ไม่มีก็ใช้ไฟล์ไทยแทน)
│   │   └── mural.jpg      รูปที่อ้างถึงในเนื้อหา วางไว้โฟลเดอร์เดียวกัน
│   └── …
├── video/                 คลิปปกติ — ชื่อโฟลเดอร์ตรงกับ deviceId
│   ├── dev-A/
│   │   └── demo.mp4       วางไฟล์ในนี้ แอปเล่นไฟล์แรกตามลำดับชื่อ
│   └── …
├── video360/              คลิป 360 องศา ลากนิ้วหมุนดูได้
│   └── site-1/
│       └── pano.mp4
└── history/               ประวัติพื้นที่ แทรกรูปได้ (marker ชนิด history)
    └── site-1/
        ├── history.txt        ภาษาไทย
        ├── history.en.txt     ภาษาอังกฤษ
        └── 2512-mill.jpg      รูปที่อ้างถึงในเนื้อหา วางไว้โฟลเดอร์เดียวกัน
```

โฟลเดอร์ `video360/` กับ `history/` ใช้กับ marker ที่ตั้ง `"kind": "history"` ไว้ใน
[`ar-markers/markers.json`](../ar-markers/markers.json) — marker ชนิดนี้จะ**ไม่แสดงค่าเซนเซอร์**

`deviceId` ต้องตรงกับที่ผูกไว้ใน [`ar-markers/markers.json`](../ar-markers/markers.json)
และตรงกับ id ใน `data/devices.json` ของ dashboard

## ไฟล์ข้อมูล (info/)

เป็นไฟล์ข้อความธรรมดา (UTF-8) แอปแยกให้สองแบบอัตโนมัติ
แต่ละจุดมีโฟลเดอร์ของตัวเอง จึงวางรูปไว้ข้าง ๆ แล้วแทรกในเนื้อหาได้
(ไฟล์แบบเก่า `info/<id>.txt` ยังอ่านได้อยู่ แต่แทรกรูปไม่ได้เพราะไม่มีที่เก็บรูป)

```
ชื่อจุดติดตั้ง: โซน A - ห้องเครื่อง     ← มีคอลอน จัดเป็นตารางหัวข้อ/ค่า
ผู้ดูแล: ฝ่ายซ่อมบำรุง ต่อ 1123

จุดนี้อยู่ใกล้คอมเพรสเซอร์ ค่าแรงสั่นสะเทือน    ← ไม่มีคอลอน แสดงเป็นข้อความยาว
จะสูงกว่าจุดอื่นเป็นปกติ

# บรรทัดที่ขึ้นต้นด้วย # เป็นคอมเมนต์ ไม่แสดงในแอป
```

กติกาเพิ่มเติม

- `## ข้อความ` ที่ต้นบรรทัดคือหัวข้อย่อย แสดงเป็นตัวหนาสีฟ้า
- คอลอนที่อยู่หลังตัวอักษรที่ 28 ถือว่าเป็นเครื่องหมายในประโยค ไม่ใช่หัวข้อ
- บรรทัดว่างใช้เว้นวรรคระหว่างย่อหน้า (ซ้อนกันหลายบรรทัดนับเป็นหนึ่ง)
- ถ้าไม่มีไฟล์ของอุปกรณ์ไหน หน้าต่างของอุปกรณ์นั้นก็แค่ไม่ขึ้น ไม่ error

## ไฟล์ประวัติ (history/)

ใช้กติกาเดียวกับไฟล์ข้อมูล แต่**แทรกรูปได้** ด้วยรูปแบบเดียวกับ Markdown

```
## ยุคโรงงาน

ก่อตั้ง: พ.ศ. 2512
พื้นที่ใช้สอย: 2,400 ตร.ม.

พ.ศ. 2530 โรงสีปิดกิจการและถูกรื้อ เพื่อสร้างอาคารโรงงานคอนกรีตหลังแรก

![อาคารโรงงานหลังแรก พ.ศ. 2530](2530-factory.jpg)
```

- ชื่อไฟล์รูปอ้างแบบสั้น ๆ ได้เลย เพราะอ่านจากโฟลเดอร์เดียวกับไฟล์ประวัติ
  (`history/<id>/`) รองรับ `.jpg` `.png` `.webp`
- ข้อความในวงเล็บเหลี่ยมกลายเป็นคำบรรยายใต้ภาพ เว้นว่างไว้ก็ได้ `![](รูป.jpg)`
- ถ้าพิมพ์ชื่อไฟล์ผิด จะเหลือกรอบว่างกับคำบรรยาย ไม่ทำให้แอปพัง
- แทรกรูปได้ทั้ง `history/` และ `info/` เพราะทั้งสองแบบมีโฟลเดอร์ของตัวเอง

## คลิป 360 องศา (video360/)

ต้องเป็นภาพแบบ **equirectangular** (อัตราส่วน 2:1) ซึ่งเป็นรูปแบบมาตรฐานที่ได้จาก
กล้อง 360 ทั่วไป (Insta360 / GoPro Max) ตอน export

แอปฉายคลิปลงทรงกลมแล้วให้ **ลากนิ้วบนภาพเพื่อหันมองรอบตัว** และหมุนตามการเอียงเครื่องด้วย

```bash
python ar-content/generate_history_demo.py    # สร้างคลิปเดโม 360 + รูปตัวอย่าง
```

## ไฟล์วิดีโอ (video/)

วางไฟล์ `.mp4` (หรือ `.m4v` `.webm` `.mkv` `.3gp`) ในโฟลเดอร์ของอุปกรณ์นั้น
ถ้ามีหลายไฟล์ แอปจะเล่นไฟล์แรกเรียงตามชื่อ

**ข้อควรระวังเรื่องความละเอียด** — คลิปถูกถอดรหัสด้วยฮาร์ดแวร์ของมือถือ
ถ้าความละเอียดสูงเกินกว่าที่เครื่องรับไหว จะเล่นไม่ได้และ popup จะขึ้นข้อความเตือนแทน
(เคยทดสอบด้วยคลิป 4500×3000 แล้วตัวถอดรหัสของ Galaxy A54 ไม่รับ)

| หัวข้อ | แนะนำ |
| --- | --- |
| ความละเอียด | 1280×720 หรือ 1920×1080 |
| รูปแบบ | H.264 (AVC) ใน `.mp4` |
| ความยาว | 10-30 วินาที เพราะเล่นวนในหน้าต่างเล็ก |
| ขนาดไฟล์ | ยิ่งเล็กยิ่งดี ทุกคลิปถูกแพ็กเข้า APK |

แปลงคลิปให้เหมาะสมด้วย ffmpeg

```bash
ffmpeg -i ต้นฉบับ.mp4 -vf scale=1280:-2 -c:v libx264 -crf 24 -preset slow -an ar-content/video/dev-A/intro.mp4
```

(`-an` ตัดเสียงออก ถ้าต้องการเสียงให้เอาออก — ในแอปเริ่มต้นปิดเสียงไว้ กดปุ่มลำโพงเพื่อเปิด)

## พฤติกรรมในแอป

เมื่อกล้องจับรูป marker ได้ จะมีหน้าต่างลอยขึ้นสามใบเรียงจากบนลงล่าง

```
┌──────────────┐
│   วิดีโอ      │   เล่นวนอัตโนมัติ ปิดเสียงไว้ กดปุ่มลำโพงเพื่อเปิด
├──────────────┤
│ ข้อมูลจุดติดตั้ง│   เลื่อนอ่านในหน้าต่างได้ถ้าข้อความยาว
├──────────────┤
│  ค่าเซนเซอร์   │   แตะเพื่อกางดูกราฟย้อนหลังกับค่าเฉลี่ย/ต่ำสุด/สูงสุด
└──────▼───────┘   ลูกศรชี้ไปที่รูป marker
```

### marker ชนิดประวัติ

marker ที่ตั้ง `"kind": "history"` จะไม่มีหน้าต่างค่าเซนเซอร์ แต่เป็น

```
┌────────────────┐          กดปุ่ม "ดูประวัติ" แล้วกลายเป็น
│  มุมมอง 360°    │        ┌──────────┬──────────┐
│  ลากนิ้วหมุนได้  │   -->   │ 360°     │ ประวัติ   │
├────────────────┤        │          │ + รูปภาพ  │
│ ประวัติ  [ดูประวัติ]│        └──────────┴──────────┘
└───────▼────────┘         กางออกไปอยู่ข้าง ๆ คลิป
```

### ทั่วไป

- หน้าต่างที่ไม่มีเนื้อหาจะไม่ขึ้น เช่นอุปกรณ์ที่ยังไม่ได้ใส่คลิปก็จะเหลือสองใบ
- ถ้าเห็นหลาย marker พร้อมกัน จะกางครบสามใบเฉพาะจุดที่**ใกล้ที่สุด**
  ส่วนจุดอื่นเหลือใบค่าเซนเซอร์ใบเดียว (มีไอคอน ▶ / เอกสารบอกว่ามีเนื้อหารออยู่)
  **แตะที่ใบนั้นเพื่อย้ายโฟกัสมาที่จุดนี้แทน**
- คลิปเล่นเฉพาะจุดที่โฟกัสอยู่ ย้ายโฟกัสหรือออกจากแอปแล้วหยุดเอง
