# Weather & Sensor Dashboard

แดชบอร์ดแสดงค่าเซนเซอร์จาก MQTT แบบเรียลไทม์ พร้อมพยากรณ์อากาศและแจ้งเตือนแผ่นดินไหว

## เปิดใช้งาน

ครั้งแรกครั้งเดียว

```bash
npm install
cd nodered && npm install && cd ..
cp .env.example .env.local
```

หลังจากนั้นดับเบิลคลิก **`start-sensor.bat`** — เปิดให้ครบทั้ง MQTT broker, Node-RED
และเว็บเซิร์ฟเวอร์ แล้วเด้งเบราว์เซอร์ไปที่แดชบอร์ดให้เอง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `start-sensor.bat` | เปิดระบบทั้งหมด |
| `stop-sensor.bat` | ปิดระบบทั้งหมด |
| `simulator.py` | ส่งค่าจำลองเพื่อทดสอบตอนยังไม่มีอุปกรณ์จริง (กด Run ใน VS Code) |

| บริการ | ที่อยู่ |
| --- | --- |
| แดชบอร์ด | http://localhost:3000/dashboard |
| Node-RED | http://localhost:1880 |
| MQTT | พอร์ต 1883 |

ต้องติดตั้ง [Mosquitto](https://mosquitto.org/download/) ไว้ก่อน

## ฟังก์ชันการทำงาน

- **กราฟเรียลไทม์** ของอุณหภูมิ ความชื้น ความสว่าง (LDR) และแรงสั่นสะเทือน เลือกช่วงเวลาได้ 5 นาที ถึง 6 ชั่วโมง
- **แจ้งเตือนอัตโนมัติ** เมื่อค่าเกินเกณฑ์ที่ตั้งไว้ใน `.env.local`
- **พยากรณ์อากาศ** รายชั่วโมงและล่วงหน้า 7 วัน ตามพิกัดของสถานี
- **แจ้งเตือนแผ่นดินไหว** จาก USGS พร้อมระยะทางจากสถานี
- **จัดการอุปกรณ์** เพิ่ม/ลบได้จากปุ่มบนแดชบอร์ด ตั้งชื่อเองแล้วระบบบอก MQTT topic ให้ไปตั้งที่อุปกรณ์
- **เลือกดูทีละอุปกรณ์** หรือดูรวมทุกตัว
- **บันทึกลงไฟล์** ข้อมูลถูกส่งต่อไป Node-RED แล้วเขียนลง `data/sensor-readings.csv` เปิดด้วย Excel ได้เลย
- **สลับภาษา** ไทย–อังกฤษ

## ตั้งค่าฝั่งอุปกรณ์

```
Broker : IP ของเครื่องที่รันเว็บ
Port   : 1883
Topic  : sensors/<ชื่ออุปกรณ์>/data
Payload: {"temperature":28.4(celcius),"humidity":61(%),"vibration":0.3(g),"light":8200(lx)} 
```

ชื่ออุปกรณ์ต้องเพิ่มในแดชบอร์ดก่อน (ปุ่ม **จัดการอุปกรณ์**) ไม่งั้นค่าที่ส่งมาจะถูกทิ้ง
